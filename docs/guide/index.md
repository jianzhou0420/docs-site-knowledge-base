# Guide

You are reading a doc-site that documents itself. The site you are browsing right now is the template — every page here is both the manual for the template and a live demonstration of how it organizes content.

## What this template gives you

- **MkDocs Material** as the renderer.
- **awesome-pages** drives the nav from the filesystem — drop a folder or file, it appears.
- **mkdocs-redirects** sends the bare URL `/` to a canonical landing page, so there is no root `index.md` to maintain.
- Per-folder `.pages` files override ordering, tab/section titles, and virtual sub-sections.
- A helper script at `scripts/check_anchors.py` reports broken same-page anchor links after you renumber sections.
