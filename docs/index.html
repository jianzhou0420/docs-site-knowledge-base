My Doc-Site

A scaffold for LLM-authored knowledge bases rendered as a fast, dependency-free static site. Drop source material in, ask Claude to organize and cross-link it, and read the result in your browser. No build step, no pip, no npm — just Python's standard library and a folder of HTML.

You are reading the site right now. Every page here is both the manual for the scaffold and a live demonstration of how it lays out content.

  • Guide — install, run, the conventions, and why the scaffold is shaped this way.
  • Recipes — copy-paste how-tos for the common changes (add a page, add a tab, group the sidebar).

How it works in one paragraph

Navigation is filesystem-driven. Each directory under docs/pages/ becomes a top tab; each .html file becomes a page. You author content inside a <main class="doc-body"> block, then run the wrap script — it regenerates the chrome (header, sidebar, breadcrumbs, on-this-page TOC, footer) from the current file tree. A tiny stdlib dev server live-reloads the browser as you edit. Branding lives in docs/_site.json; per-tab nav lives in docs/pages/<tab>/_tab.json. That's the whole system.
