Demo — built by dropping a folder

This entire tab was created by dropping docs/pages/demo/ into the repo — no _tab.json, no required index.html. The sidebar on the left is a live mirror of the folder tree. Open each item and compare it to the structure below.

The folder behind this tab

demo/
├── index.html            ← you are here (this tab's default page)
├── a-loose-page.html     ← a page, sibling of the folders
├── guides/               ← folder WITH index.html → clickable divider
│   ├── index.html
│   ├── first-guide.html
│   └── nested/           ← nests to any depth
│       ├── index.html
│       └── deep-page.html
└── extras/               ← folder WITHOUT index.html → plain divider
    ├── one.html
    └── two.html

What to notice

A folder = a divider. Its index.html (if present) is the divider's clickable default page. Loose .html files are pages alongside the folders. It recurses to any depth. Delete this folder anytime — it's just a demo.
