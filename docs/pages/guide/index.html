Guide

You are reading a doc-site that documents itself. The site you are browsing right now is the template — every page is both the manual for the scaffold and a live demonstration of how it organizes content.

What this template gives you

  • Zero dependencies. Pure Python standard library — no pip, no npm, no build step. If you have python3, you can run it.
  • Filesystem-driven nav. Each directory under docs/pages/ becomes a tab; each .html file becomes a page. Drop a file in, it appears.
  • Author content, not chrome. You write a <main class="doc-body"> block; the wrap script regenerates the header, sidebar, breadcrumbs, on-this-page TOC, and footer for you.
  • Live-reload dev server. A stdlib HTTP server watches the tree and pushes a browser reload over Server-Sent Events when anything changes.
  • One config file for branding (docs/_site.json) and one per tab for nav (_tab.json).
