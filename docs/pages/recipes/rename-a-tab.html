Rename a tab

Two different things people call "rename a tab":

A. Change the label, keep the URL

The label shown in the header is separate from the directory name (which drives the URL). To change only the label, edit the tab's _tab.json:

{
  "label": "Developer Handbook"
}

Re-run python3 docs/_lib/_wrap_handwritten.py. No files move, existing links work, done.

B. Change the URL too

You want the URL to change from /pages/guide/... to /pages/handbook/.... Rename the directory:

git mv docs/pages/guide docs/pages/handbook

Then:

  1. Update any cross-tab links that point into the renamed directory. Find them: 
    grep -rn 'pages/guide/' docs/
grep -rn '\.\./guide/' docs/pages/
  2. Re-run the wrap script so the new tab's pages get fresh chrome and breadcrumbs: 
    python3 docs/_lib/_wrap_handwritten.py
  3. If you need to preserve old bookmarks, drop a tiny redirect stub at the old path (a plain HTML <meta http-equiv="refresh"> page), since there's no redirect plugin.

Rule of thumb: rename the label (A) freely; rename the URL (B) only when you really need to.
